JEV EVALUATION

좋은 의견을 판단하는 기준

JEV의 Score는 각 기준을 5단계(0~4)로 평가합니다. 아래 배점으로 환산하여 각 답변의 품질 점수를 계산합니다.

논리성주장과 결론이 일관되게 이어지는가?30점
실행 가능성질문의 상황에서 실제로 실행할 수 있는가?30점
위험 고려반대 근거와 놓칠 수 있는 위험을 다뤘는가?25점
질문 적합성질문의 핵심과 조건에 직접 답하는가?15점

기준별 환산 점수 = 원점수 ÷ 4 × 배점. 합계는 100점 만점이며 평균은 평가된 답변만 포함합니다.
새 실행의 최종 판정은 YES / NO / 조건부 권고입니다. 필요한 정보가 부족하면 가정과 확인 조건을 포함한 실행안을 제시합니다. 사용할 수 없는 AI는 제외하며, 최초 답변이나 재검증이 모두 실패하면 최종 의견을 작성하지 않습니다. 품질 점수는 최초 답변에 대한 점수이며 재검증 점수와 구분합니다. Confidence와 판정별 분포는 사실의 정확도나 성공 확률을 뜻하지 않습니다.
LOCAL CONNECTIONS

내 컴퓨터의 AI와 연결

카드마다 위에서부터 차례대로 준비하세요. 「사용 가능」이 뜬 AI만 판단에 참여합니다. Claude·ChatGPT는 공식 CLI 구독 계정으로, Gemini·JEV는 API 키로 연결합니다.

사전 검토와 검색어 정리에도 선택 시간이 적용됩니다. 공개 조사는 요청당 최대 선택 시간의 2배(4·6·10분)이며, 부족한 범위는 한 차례 추가 조사합니다. JEV 사전 검토와 출처 확인 시간이 더해집니다. Claude·ChatGPT는 초안 → 상호 검토 → AI별 종합에 각각 적용됩니다. 토론 대기는 선택 시간의 최대 3배(6·9·15분), 각 7회 요청입니다. Gemini의 최초 의견은 1회 요청입니다. 이후 JEV 중간 판정, 각 AI의 재검증, JEV 재평가, 최종 작성 시간이 더해집니다. 재검증과 최종 작성에도 선택 시간이 각각 적용되며, 실패 시 다른 AI를 시도하면 대기가 더 길어질 수 있습니다.

저장된 API 키는 메인 프로세스에서만 사용하며 화면·판단 기록·업데이트 파일에 포함하지 않습니다. Gemini 무료 API에 회사 기밀·개인정보를 입력하지 마세요.

각 AI와 JEV가 질문의 명확성과 첨부 자료의 충분성을 먼저 검토합니다. 추가 확인이 필요할 때만 질문이나 자료를 요청하고, 충분히 명확하면 바로 뉴스·논문·공식 자료를 조사합니다. 수집된 근거를 공유한 뒤 Claude·ChatGPT의 3인 토론과 Gemini 검토, JEV 중간 판정, 각 AI의 독립 재검증과 JEV 재평가를 거쳐 최종 실행안을 작성합니다.

  1. 판단할 질문을 적고 도움이 되는 파일을 첨부하세요.
  2. 사전 검토에서 추가 질문이나 자료를 요청한 경우 답변하고 필요한 파일을 첨부하세요.
  3. 공개 자료 조사 결과와 출처를 확인하고, AI 토론과 JEV 재검증 과정을 비교하세요.
  4. 최종 실행안의 근거, 가정과 조건을 확인하고 결정하세요.

JEV는 평가 점수와 판정을 제공하며 서술형 답변을 작성하지 않습니다. 모든 응답 AI가 중간 판정을 재검증하며, 별도의 작성 AI가 JEV 재평가와 보완된 의견을 반영해 최종 실행안을 작성합니다. 작성 AI를 화면에 표시합니다. 공개 자료의 출처와 수집 상태, 확인하지 못한 항목을 구분해 표시합니다. 조사 결과와 최종 의견의 근거·가정·조건을 함께 확인하세요. 질문·첨부 자료·조사 결과·답변·종합 의견이 로컬 기록에 저장됩니다.
